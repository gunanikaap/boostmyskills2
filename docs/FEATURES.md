# Features

- Public home page matching the verified live-site structure.
- Data-driven micro-programmes and derived micro-credentials.
- Legacy route redirects for /programs/, /courses, /privacy, /cookie_policy, /tos, /login and /register.
- Supabase sign up, sign in and password reset forms.
- Protected dashboard and account pages.
- Login-gated enrolment route with Supabase upsert storage.
- Contact form with Zod validation and Supabase storage when configured.
- Local copies of public images from the legacy site.
- Responsive header/mobile menu.
- Playwright smoke tests for main routes, auth pages, catalogue and mobile navigation.
